# 🛒 React Shopping Cart

A responsive and modern **Shopping Cart Web Application** built using **React.js and Vite**.

This project demonstrates the implementation of a product shopping experience with product listing, shopping cart management, quantity updates, item removal, and responsive UI.

---

## 🌐 Live Demo

👉 https://react-shopping-cart-pi-liart.vercel.app/

---

# ✨ Features

## 🛍️ Product Features

- Product listing
- Product cards
- Product information
- Product images
- Product pricing
- Add product to cart

## 🛒 Shopping Cart

- Add products to cart
- Remove products from cart
- Increase product quantity
- Decrease product quantity
- Cart item count
- Calculate total price
- View cart items

## 🎨 User Interface

- Responsive design
- Modern shopping interface
- Reusable React components
- Clean layout
- Mobile-friendly interface
